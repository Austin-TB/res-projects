# res-projects

Project metadata for [resweb2.0](https://github.com/Austin-TB/resweb2.0): one JSON file per project under `projects/`.

Example shape:

```json
{
  "title": "My Project",
  "description": "Short description.",
  "github_link": "https://github.com/you/repo",
  "deployed_link": "https://example.com"
}
```

Optional fields: `github_link`, `deployed_link`.
